### Спринт 2 · Фікси адаптації під планшет — кабінет автора (2026-09-24) — ▶ НАСТУПНЕ ДЛЯ АГЕНТА (після фіксів сторінки книги вище)

Диктовка Анатолія, тестування на планшеті. Скоуп: кабінет автора `/dashboard/...`. Приймати на проді в портретній (768–834 px) і ландшафтній (1024–1194 px) орієнтації. Кнопки, адаптацію, свайп і гортання брати з готових компонентів shadcn/ui, які вже є в проєкті, без самописних рішень.

**Спільне правило для кнопок:** одна стандартна кнопка застосунку (shadcn `Button`, варіанти default/outline/secondary). Усі дії у вкладках книги поводяться однаково (див. T2.1).

- [x] **T1. «Мої книги» (`/dashboard/books`): нижній рядок картки.** Мета wrap, «Відкрити» окремо, «Видалити» в `⋯` DropdownMenu. До `lg` — два рядки.
- [x] **T2. «Вихідні дані», збереження: текст повідомлення.** Більше не згадує кнопку «Опублікувати із змінами» нижче — відсилає на вкладку «Публікація».
- [x] **T2.1. Єдина поведінка кнопок збереження у всіх вкладках.**
  - Приймання: після натискання кнопка стає неактивною (disabled) і показує стан «Збереження…», а потім «Збережено». Знову активною вона стає лише після нових змін (dirty state). Вибрати одну схему (за основу взяти те, як це зроблено у вкладці «Рукопис», якщо там краще) і застосувати її у всіх вкладках: «Вихідні дані», «Обкладинка», «Ціна та розповсюдження», «Рукопис».
- [x] **T3. Горизонтальний скролбар під вкладками налазить на вкладки.** `pb-2.5` на `OutputDataTabs`.
- [x] **T4. Вкладка «Обкладинка»: передперегляд на ширину планшета.** Прибрано `max-w-[200px]` — сітка на всю ширину картки.
- [x] **T4.1. Передперегляд обкладинки гортається свайпом.** Той самий `BookCoverCarousel`, що й F1.1.
- [ ] **T4.2. «Обкладинка для друку»: вже виглядає добре, не чіпати.** Лише перевірити після деплою.
- [x] **T4.3. Кнопка «Редагувати обкладинку» у стандартному стилі кнопки застосунку.**
- [x] **T4.4. Кнопка «До дашборду книги» у стандартному стилі кнопки застосунку.** (layout усіх вкладок output-data)
- [x] **T5. «Ціна та розповсюдження»: таблиця на ширину планшета.**
  - Приймання: колонка з ціною в магазині достатньо широка, щоб число і «грн» завжди стояли в одному рядку (`white-space: nowrap` або мінімальна ширина колонки).
- [x] **T5.1. Видно, що таблицю можна прокрутити вбік.**
  - Приймання: таблиця гортається вліво і вправо, а біля правого краю є тінь або градієнт, поки праворуч ще є вміст (готове рішення, наприклад ScrollArea або горизонтальна тінь-підказка). Коли таблицю прокручено до кінця, тінь зникає.
- [x] **T5.2. Кнопка «До дашборду книги» стандартизована в усіх вкладках розділу книги.** (зроблено разом із T4.4)
- [x] **T6. «Рукопис»: адаптація під планшет.**
  - Приймання: на планшеті лівий і правий сайдбари згорнуті за замовчуванням і відкриваються за потреби (shadcn Sheet або Sidebar collapsible). Рукопис займає всю ширину екрана, його можна і переглядати, і редагувати. Тулбар форматування плаває поверх рукопису, прикріплений до правого краю, і згортається в одну іконку (Popover або floating toolbar). Десктоп-версія лишається без змін.
- [x] **T7. «Обкладинка», вкладка м'яка/тверда: канва з обкладинкою не адаптована.**
  - Приймання: канва редактора обкладинки масштабується під ширину планшета в обох орієнтаціях, повністю видна без горизонтального скролу сторінки, а елементи керування доступні.
- [x] **T8. «Передперегляд»: канва враховує орієнтацію планшета.**
  - Приймання: у портретній орієнтації на екрані одна сторінка на всю ширину, а гортання (свайп або тап) відкриває наступну. У ландшафтній показується розворот книги, який гортається так само, як на десктопі. Коли планшет повертають, вигляд перемикається без перезавантаження сторінки.

Готово, коли всі пункти перевірені на планшеті (або в DevTools на 768×1024 і 1024×768) на https://ulit.render.ua, а також `pnpm --filter web build` і `pnpm typecheck` зелені.
