## Alpha exit (гіпотеза з BUSINESS.md)

Автор: договір → книга → модерація → `PUBLISHED` у магазині.  
Покупець: кошик → LiqPay → файли.

**Не альфа:** реальний ISBN-пул, авто-KDP/D2D/Google, автовиплати, обов’язковий WayForPay, аудіо/POD.

## Спринт 2 — критичний шлях автора (НАСТУПНИЙ)

Живий прохід на проді, потім фікси. Нові екрани Ridero не малювати.

1. Реєстрація → підтвердження email → договір → книга → рукопис → обкладинка → вихідні дані → модерація → `PUBLISHED`.
2. Покупець: кошик → LiqPay (sandbox або тестовий платіж) → файли на `/orders/:id`.
3. Друкарські хвости, якщо ламають «готову книгу»:
   - **T-2065** — парність / кратність 4 сторінок у print PDF.
   - **T-2055** — `pageCount` / корінець від реального `printPageCount`.
4. Toolbar рукопису (залишок **T-1942**: таблиці / посилання) — лише якщо живий прохід упреться.

Перевіряти в браузері на https://ulit.render.ua, не лише typecheck.

Поки E2E з `continue-on-error` — фічу не вважати готовою.
