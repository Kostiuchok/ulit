Дата: 2026-10-05 (кінець сесії). Прод: https://ulit.render.ua · останній задеплоєний коміт на момент запису — `4ebb36a`; у черзі деплою `03b6b07`, `f3d6bcc`.

Критерій виходу з альфи (`BUSINESS.md`, `ALPHA-SPRINTS.md`):
**автор** — договір → книга → модерація → `PUBLISHED` у магазині; **покупець** — кошик → LiqPay → файли; **автор бачить роялті**.

## 1. Звіт: що зроблено за сесію 2026-10-05

### Редизайн кабінету книги (WF-SPEC.md) — усі фази закрито
- Phase 2: дашборд книги (13 кроків, «Наступний крок»), сайдбар, «Вихідні дані», «Огляд», спільна нижня панель збереження.
- Phase 3: схвалення зміни обкладинки адміном, блок «що змінилось», правило нового видання для ISBN.
- Phase 4: сторінка «Обкладинка» — стани «завантажено / на перевірці / заблоковано на 90 днів», превʼю, «Замінити файлом».
- 06d/06e: 14 готових стилів обкладинки, тема від одного кольору, задня сторона, корінець, QR.
- 08: редактор обкладинки — шари, «Вибране / Дизайн», нижня панель.

### Обкладинка: одна система замість двох
- Готовий стиль відкривається в редакторі **шарами** (текст редагується, декор — один шар «Фон стилю»); під полотном стрічка всіх 14 стилів; «Колір теми».
- Редактор вирівняно з макетами 46:2 / 47:2: порядок і іконки шарів, перемикачі блоків задньої сторони з джерелом даних, смуга корінця з виноскою.
- Якщо обкладинка — завантажений файл, редактор показує саме її (а не «нову»).

### Вильоти для друкарні
- Константа вильоту 1,5 мм (було 3,2 мм — цифра Amazon KDP).
- Редактор і готові стилі малюють **справжній** вильот; файл для друкарні (зад · корінець · перед + вильоти, PNG 300 dpi) — в адмінці → «Файли книги».
- Для обкладинок, завантажених файлом, вильот дзеркальний (адмінка про це попереджає).

### Форми кабінету «без милиць» (FORMS-REFACTOR-PLAN.md) — етапи 0–4 з 5
- Правила обов'язкових полів — в одному місці, спільному для сервера і сторінки (34 тести).
- Порожнє обов'язкове поле завжди підсвічене з підказкою; «Зберегти» неактивне лише з видимою причиною.
- «Змінено» — порівняння зі збереженим, а не прапорець: повернув значення — позначка зникла.
- «Ціна»: ціни, знижка і магазини зберігаються одним запитом — усе або нічого.
- Вихід зі сторінки з незбереженим питає: вкладки, сайдбар, кнопка «Назад», закриття вкладки.
- Знайдено й усунено причину «вкладки не перемикаються»: нескінченний цикл рендерів у панелі збереження (журнал CLAUDE.md #39).

### Автотести
- Браузерні тести тепер запускаються **після кожного деплою** на живому сайті (раніше — до деплою, і всі тести з входом падали через помилку в самому тесті).
- 25 тестів: вхід, кабінет, магазин, і 7 на форми (підсвічування, «Змінено», вихід зі сторінки, «Назад», вкладки).
- Тестовий акаунт `e2e@render.ua` працює; постійна тестова чернетка — «E2E чернетка (не видаляти)».

### Помилки цієї сесії, про які треба знати
- Перший варіант автотестів створював нову чернетку в кожному тесті — в адмінці з'явились 4 порожні копії. Виправлено; копії досі на проді (див. чекліст, розділ D).
- У репозиторій випадково потрапили два локальні PDF (`docs/print.pdf`, `docs/print (1).pdf`). З дерева прибрано наступним комітом, **в історії гіта вони лишились** (репозиторій публічний). Власник сказав «все добре»; історію не переписували.
- Скрипти правок двічі зіпсували символи у файлах (зворотні скісні риски, нуль-символ) — знайдено й виправлено до деплою; тепер усі джерела скануються на керівні символи (журнал #41).

## 2. Чекліст: що лишилось до виходу з альфи

Позначки: 🔴 блокує альфу · 🟡 треба зробити до запрошення авторів · ⚪ можна після альфи.

### A. Блокери критерію виходу

- [ ] 🔴 **Ключі LiqPay на проді.** `LIQPAY_PUBLIC_KEY` і `LIQPAY_PRIVATE_KEY` порожні (перевірено 2026-10-05). Без них покупець не може заплатити — половина критерію виходу. **Дія власника:** видати ключі (sandbox для перевірки, бойові для запуску) і вписати в `.env.production` на VPS; після цього `--force-recreate api web`.
- [ ] 🔴 **Живий прохід покупця.** Кошик → оплата LiqPay → файли на `/orders/:id` → нарахування роялті автору. Не перевірявся жодного разу з реальними ключами.
- [ ] 🔴 **Живий прохід автора від нуля до магазину** новим акаунтом: реєстрація → підтвердження пошти → договір → книга → рукопис → обкладинка → вихідні дані → ціна → модерація → `PUBLISHED`. Частинами пройдено багато разів, одним проходом на свіжому акаунті після сьогоднішніх змін — ні.
- [ ] 🔴 **Автор бачить роялті після реальної покупки.** Сторінка є; з реальною оплатою не перевірялась (залежить від LiqPay).

### B. Перевірити наживо зроблене 2026-10-05 (не перевірено або перевірено частково)

- [ ] 🟡 Файл для друкарні з адмінки: розміри, вильоти, чи приймає друкарня PNG (розділ «Вильоти для друкарні»).

## 3. Найкоротший шлях до альфи

1. **Власник:** ключі LiqPay (sandbox) на прод.
2. Прохід покупця з тестовою оплатою; прохід автора новим акаунтом. Виправити, що знайдеться.
3. Пройти розділ B чекліста (перевірка зробленого 05.10).
4. Прибрати тестові книги з магазину (розділ D).
5. Sentry DSN; зняти `continue-on-error` з автотестів.
6. Бойові ключі LiqPay → запрошення перших 1–3 авторів.

Пункти 1–2 — єдине, чого бракує самому критерію виходу. Решта — щоб перші автори не натрапили на тестові дані й щоб про їхні помилки хтось дізнався.
