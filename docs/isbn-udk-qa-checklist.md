# QA-чекліст: ISBN/авторське право + пакет для Книжкової палати (2026-09-02)

## Авторське право / попередня публікація (Вихідні дані → Інформація)

- [x] Заповнити Рік/Власника/Номер свідоцтва, зберегти, перезавантажити сторінку → значення збереглись
- [x] Ввести ISBN з невалідною контрольною цифрою → "Невалідний ISBN-13", нічого не збереглось
- [x] Ввести ISBN, що вже присвоєно іншій книзі → "Цей ISBN вже присвоєно іншій книзі"
- [x] Спробувати зберегти ISBN БЕЗ галочки підтвердження → кнопка "Зберегти ISBN" неактивна
- [x] Поставити галочку + валідний унікальний ISBN → зберігається, стає read-only з ✓
- [x] Після присвоєння: "Готовність до оформлення ISBN" замінюється на "✓ ISBN вже присвоєно — реєстрація в Книжковій палаті не потрібна"
- [x] "Огляд перед публікацією" показує рядок ISBN

## Повідомлення "Збережено як чернетку" (опублікована книга, зміна Назви/Анотації/Жанру)

- [x] Після збереження повідомлення НЕ зникає само (раніше зникало через 3с)
- [x] Натискання × у правому верхньому куті закриває повідомлення
- [x] Плейсхолдер поля "Номер свідоцтва" більше не містить "proza.ru, stihi.ru"

## Кнопки на дашборді книги (заголовок)

- [x] На опублікованій книзі з незбереженими змінами (назва/анотація/жанр/рукопис) кнопка "Опублікувати із змінами" стоїть на одному рівні з "Редагувати"/"Зняти з публікації"/"Сайт книги"
- [x] Повідомлення "Ще не на сайті — очікує на надсилання: ..." показується окремим рядком під усім рядком кнопок

## Пакет для Книжкової палати (адмінка)

- [x] `/admin/isbn-queue` — відкрити книгу з черги, перевірити рядок з мовою/жанром/кількістю сторінок
- [x] Там же — Файл 4 (задня обкладинка) з'являється, якщо є `backCoverUrl`
- [x] Там же — текст з e-mail для УДК (`udc2920054@ukr.net`, тема "УДК, [назва видавця]")
- [x] `/admin/books/[id]/distribute` → секція "Реєстрація ISBN + УДК" — та сама розширена інформація + рядок ISBN/УДК/авт. знак, якщо вже присвоєно
- [x] На книзі БЕЗ ISBN/УДК — жовте попередження про застарілий колофон/штрихкод НЕ показується
- [x] На книзі З ISBN або УДК — попередження показується, посилання "колофон рукопису"/"обкладинка" ведуть на правильні сторінки
- [x] Крок 3 "Присвоїти ISBN + УДК + авторський знак" — форма і збереження працюють як раніше (без регресій)
- [x] Файл 1 ("заявка.txt") завантажується і містить назву/ПІБ/мову/жанр/сторінки/ISBN/УДК/ББК/авт.знак/анотацію

# QA-чекліст: перейменування ISBN→УДК, документи видавця, рукопис (2026-09-03)

## Профіль: ПІБ + автопідстановка (Налаштування профілю)

- [x] Акаунт із порожнім ПІБ → `/dashboard/settings` показує редаговані поля Прізвище/Ім'я/По батькові
- [x] Заповнити й зберегти → перезавантажити сторінку → показується read-only + посилання "Змінити договір"
- [x] Повторна спроба PATCH тих самих полів напряму (напр. через збережений старий запит) → 400
- [ ] Завантажити договір (`/dashboard/settings/contract` → "Завантажити договір") → ім'я в тексті документа береться зі структурованого ПІБ, не зі старого `session.user.name`
- [ ] Нова книга без `bookAuthors` → відкрити Вихідні дані → поле автора вже підставлене з профілю (ПІБ + фото), можна відредагувати під конкретну книгу і зберегти
- [ ] Поле "Біографія автора" на Вихідних даних: порожнє → підтягується з профілю; редагування на цій сторінці зберігається і в профілі теж (перевірити на `/dashboard/settings`)

## Рукопис / передперегляд

- [ ] Відкрити Рукопис книги, що раніше мала "запечений" титул/колофон (тестові книги цієї сесії) → на початку тексту більше немає титульної/колофонної сторінки
- [ ] Передперегляд рукопису (`/manuscript/preview`) → після Зміст одразу йде текст, без порожньої сторінки
- [ ] Задня обкладинка з'являється останньою сторінкою PDF (якщо у книги є `backCoverUrl`)
- [ ] Титульна сторінка (1) — ім'я автора/назва/рік вирівняні по лівому краю, без відступу абзацу, схоже на `docs/ulit-reference/SCREENSHOTS/86`
- [ ] Колофон (2) — стековані УДК/авт.знак, жирний підпис автора, бібліографічний рядок, бейдж вікового рейтингу, копірайт унизу; **рядка ББК ніде немає**
- [ ] Змінити щось на Вихідних даних (напр. анотацію), НЕ чіпаючи сам рукопис → відкрити передперегляд ще раз → PDF перерендерився з новими даними (не застряг зі старою версією)

## Перейменування ISBN → УДК

- [ ] Сайдбар адмінки: пункт "🔖 Реєстрація УДК" веде на `/admin/udk-queue` (не `/admin/isbn-queue`)
- [ ] `/admin/udk-queue` — файли всіх книг розкриті одразу (без кліку "Показати файли")
- [ ] Книга з уже присвоєним ISBN, але без УДК — **з'являється** в черзі (раніше зникала б помилково)
- [ ] Книга з присвоєним УДК — зникає з черги незалежно від стану ISBN
- [ ] Кнопка "✉ Написати лист на УДК" відкриває поштовий клієнт із заповненими темою/текстом
- [ ] `/admin/books/[id]/distribute` → секція "Реєстрація УДК (+ ISBN)"; крок 3 "Присвоїти ISBN + УДК" — рівно 3 поля (ISBN, Авторський знак, УДК), **без ББК**
- [ ] На Вихідних даних чекліст тепер зветься "Готовність до реєстрації УДК" і ховається лише коли `udcCode` присвоєно (не коли лише ISBN присвоєно)
- [ ] Дашборд книги (`/dashboard/books/[id]`) → крок таймлайну "Отримати УДК" (не "Отримати ISBN")

## Документи видавця (`/admin/dashboard`)

- [ ] Нова картка "Документи видавця (для ISBN + УДК)" під KPI-картками, 4 рядки, усі "○ не завантажено"
- [ ] Завантажити файл в один рядок → статус "✓", дата, посилання "переглянути" відкриває файл
- [ ] Підсумковий банер показує "Бракує N з 4" / після завантаження всіх 4 — "✓ Усі документи готові до відправки"

## Дашборд автора

- [ ] `/dashboard/settings` — перший пункт меню "Кабінет автора" веде на `/dashboard`, підсвічується лише на цій сторінці (не на інших вкладках Налаштувань)

# QA-чекліст: договір, обов'язкові поля, вихідні дані, редактор обкладинки (2026-09-04)

## `/dashboard/settings/contract` — обов'язкові поля + платіжні реквізити

- [ ] Форма "Змінити договір" — червоні `*` біля Прізвище/Ім'я/Дата народження/Серія та номер паспорта/Адреса реєстрації; По батькові, Громадянство, Причина зміни — без `*`
- [ ] Форма підписання (ще не підписано) — червоні `*` біля ІПН/РНОКПП, IBAN для виплат, Паспортні дані або дані ФОП
- [ ] **Вже підписаний договір**: під зеленою карткою "Договір укладено" з'явилась нова картка "Платіжні реквізити" з тими самими 3 полями, попередньо заповненими поточними значеннями
- [ ] Змінити IBAN у цій новій картці → "Зберегти реквізити" → з'являється "✓ Реквізити збережено"; перезавантажити сторінку → нове значення збереглось
- [ ] "Завантажити договір" (Word) — у розділі підписів тепер також рядки Дата народження/Громадянство/Серія та номер паспорта/Адреса реєстрації (якщо колись заповнювались через "Змінити договір"), не лише ПІБ/ІПН/паспорт(вільний текст)/IBAN

## `/dashboard/settings` — підказка під "Ім'я автора"

- [ ] Під полем "Ім'я автора" з'явився короткий текст про псевдонім і зв'язок з "Публічний slug"

## `/dashboard/books/new` (візард) — бейджі анотації + вікові обмеження

- [ ] Крок 1, поле "Анотація" — під полем ті самі бейджі D2D 50+/Google Play 150+/Amazon KDP 250+, що й на Вихідних даних, підсвічуються ✓ зеленим по мірі набору тексту
- [ ] Створити нову книгу, на кроці 1 обрати Вікові обмеження, пройти візард до кінця → відкрити Вихідні дані цієї книги → поле "Вікові обмеження" вже заповнене (раніше губилось при створенні)

## `/dashboard/books/[id]/output-data` — стійкість до перемикання вкладок + нові блоки

- [ ] Почати заповнювати форму (Підзаголовок, Вікові обмеження, вручну ввести Прізвище автора БЕЗ натискання "+ Додати автора") → переключитись в інше вікно/програму й повернутись назад → введені дані НЕ зникли
- [ ] Натиснути "+ Додати автора" (бейджик з'явився) → переключитись в інше вікно й повернутись → бейджик автора НЕ зникає
- [ ] Після блоку "Рукопис" з'явився новий блок "Обкладинка" з посиланням на редактор обкладинки та статусом ✓/○ "Обкладинка завантажена"/"ще не створена"
- [ ] Кожен заголовок блоку (Інформація/Рукопис/Обкладинка/Ціна та розповсюдження/Огляд перед публікацією/Публікація) має кружечок ✓ (зелений, виконано) або ○ (жовтий, не виконано) ліворуч від вертикальної лінії — звірити з реальним станом (напр. блок без обкладинки → ○ як в "Обкладинка", так і в "Публікація")
- [ ] "Огляд перед публікацією" — новий рядок "Обкладинка: Завантажено/Не завантажено"

## `/dashboard/books/[id]/cover` — критичний баг ілюстрації + нові можливості

- [ ] Завантажити ілюстрацію (не фон) в режимі "Електронна версія", розмістити її (посунути/зменшити) → переключитись на "М'яка обкладинка" → ілюстрація на ПЕРЕДНІЙ (правій) панелі, НЕ на задній і не під фоном
- [ ] Те саме навпаки: завантажити ілюстрацію в "М'яка обкладинка", переключитись на "Тверда обкладинка" і на "Електронна версія" → щоразу на передній панелі, коректно обрізана
- [ ] Зберегти книгу, перезавантажити сторінку (`F5`) → ілюстрація так само на передній панелі у всіх трьох форматів
- [ ] "Завантажити зображення для фону" → після завантаження зображення тепер можна виділити мишкою, перетягнути, змінити розмір за кутові маркери, і кнопка "Кадрувати зображення" працює так само, як для ілюстрації
- [ ] Посунути/змасштабувати фонове зображення → переключити формат (ебук ↔ друк) і назад → позиція фону НЕ скидається до автоцентрування
- [ ] Виділити будь-який елемент (текст, ілюстрацію, фон) → він БІЛЬШЕ не "стрибає" на передній план поверх інших елементів обкладинки
- [ ] Навести мишкою (без кліку) на будь-який елемент обкладинки → з'являється яскравий контур навколо нього; клік — як раніше, з'являються елементи керування
- [ ] Виділити будь-який об'єкт і натиснути стрілки клавіатури → об'єкт посувається на 1px (Shift+стрілка — на 10px)

## `/dashboard/books/[id]/manuscript/preview` — задня обкладинка у флипбуку

- [ ] Книга з `backCoverUrl` — гортати до останньої сторінки флипбука → задня обкладинка показується як суцільне зображення на всю сторінку (як лицьова обкладинка), а НЕ як звичайна "внутрішня" сторінка з білими полями
