## ✅ Задеплоєно — потребує перевірки

### Передперегляд книги, ландшафт (`/dashboard/books/:id/manuscript/preview`)

- [ ] **Розворот книги влазить по висоті на планшеті в альбомній орієнтації** — відкрий на планшеті (або DevTools responsive, 1024×768 чи подібне), книга не вилазить знизу екрана; гортання працює так само, як раніше.

### Дашборд книги (`/dashboard/books/:id`)

- [ ] **«Наступний крок»** — зелена картка вгорі показує актуальний наступний крок і правильний лічильник «N з 13»; кнопка веде на відповідну сторінку (або на «Публікацію», якщо все готово).
- [ ] **«N з 13 кроків виконано»** — картка розгортається/згортається; розгорнутий список показує всі 13 пунктів з ✓/○; «Отримати УДК» має бейдж «в процесі» / «необов'язково» / «отримано» (не блокує "наступний крок").
- [ ] **Поточний крок видно і в згорнутому стані** — окремий рядок з амбер-бейджем «в процесі» під списком.
- [ ] **Шапка: «Редагувати» / «Сайт книги»** — для опублікованої книги без змін «Сайт книги» зелена (primary); коли є незбережені зміни вихідних даних чи рукопису — з'являється зелена «Надіслати на модерацію (N)», а «Сайт книги» стає контурною.
- [ ] **Меню «⋯»** — «Копіювати посилання на книгу» (копіює реальне посилання, активне лише для опублікованої книги), «Історія публікацій» (сіра заглушка, не клікабельна), «Зняти з публікації» (червона, з діалогом підтвердження, лише для опублікованої), «Видалити книгу» (червона, з діалогом підтвердження) — перевір, що видалення книги звідси працює і перекидає на список книг.
- [ ] **Амбер-банер «Зміни на модерацію»** — з'являється лише коли реально є незбережені зміни вихідних даних/рукопису; перелічує правильні блоки; посилання «Що змінилось?» веде на «Огляд».
- [ ] **Ціни — 3 плитки** (Електронна / Друк м'яка / Друк тверда) над кроками, з посиланням «Змінити ціну» в заголовку картки.
- [ ] **«Зробіть книгу кращою»** — лише «Замовити тираж» клікабельна (веде на реальну сторінку); решта послуг — один рядок «Скоро» без цін і кнопок.

### Сайдбар (ліва панель кабінету автора)

- [ ] **Ширина 264px** — жоден пункт не обрізається «…».
- [ ] **«Видалити»** зник із групи «Редагувати книгу» (тепер лише в «⋯» дашборду).
- [ ] **Групи:** «Редагувати книгу» / «У магазинах» / «Реклама» — у кожній лише робочі посилання.
- [ ] **«Скоро: ще N розділів»** — один розгортний розділ унизу навігації книги, об'єднує всі неактивні пункти (Завантаження, Статистика, Обговорення, Знайти читачів, Включити акцію).

### Вихідні дані (`/dashboard/books/:id/output-data`)

- [ ] **Назва скрізь однакова** — у сайдбарі, у степері вгорі і в заголовку сторінки тепер «Вихідні дані» (не «Інформація»).
- [ ] **Інфо-банер** для вже опублікованої книги: синій банер під степером пояснює, що зміни не йдуть у магазин одразу, з посиланням «До дашборду книги».
- [ ] **Шкала прогресу анотації** — під полем з'явилась смужка-прогресбар із позначками 50/120/150/250/500, зелені позначки вмикаються наживо під час друку; ряд чипів-«легенда» під шкалою лишився як був.
- [ ] **Блок «Декларації»** (чекбокс ШІ) тепер одразу під анотацією, а не в самому кінці форми.
- [ ] **ISBN зберігається разом з формою** — заповни «ISBN, вже присвоєний книзі раніше» + постав галочку підтвердження, натисни загальну «Зберегти зміни» внизу (не було окремої кнопки «Зберегти ISBN» — її більше немає) — ISBN має зберегтись.
- [ ] **Нова валідація:** постав «Рік» в «Авторське право», залиш «Власник авторського права» порожнім → секція сама розгортається і показує червону помилку під полем; збереження заблоковане, поки не заповниш.
- [ ] **Спільна sticky-панель знизу** — «← До дашборду книги» + статус + кнопка «Зберегти зміни» тепер завжди прилипла до низу екрана (раніше кнопка була всередині картки, прокручувалась разом з формою).

### Ціна та розповсюдження (`/dashboard/books/:id/output-data/price`)

- [ ] **Кнопка збереження і статус переїхали в ту саму sticky-панель знизу**, що й на «Вихідних даних» — перевір, що сама логіка збереження, валідації і повідомлень («Є незбережені зміни у N блоках · ULIT: одразу після збереження», «Збережено ✓ · час · ULIT: застосовано») працює так само, як до цього. **Це найважливіший пункт для перевірки** — єдина сторінка, де існуючу (вже прийняту) логіку технічно чіпали, хоч і не повинні були змінити поведінку.

### Огляд перед публікацією (`/dashboard/books/:id/output-data/review`)

- [ ] **4 картки-секції** (Вихідні дані / Рукопис / Обкладинка / Ціна та розповсюдження), кожна з посиланням «Змінити» на свою сторінку.
- [ ] **Амбер-рамка** на картці «Вихідні дані» чи «Рукопис», коли там є незбережені зміни, що чекають модерації (той самий список, що в банері дашборду).
- [ ] **Одна таблиця** Варіант / Ціна для читача / Ваш прибуток / Магазин — прибуток показує реальний гонорар автора, не діапазон.
- [ ] **Чипи платформ** — «Платформи: N обрано», ULIT завжди присутній; посилання «Додати магазини» веде на «Ціну».
- [ ] **УДК-чекліст** — заголовок показує «Готовність до реєстрації УДК · N з 4»; більше немає тексту про `docs/isbn-udc-requirements.md`.
- [ ] **Нова кнопка «Надіслати на модерацію (N)»** у sticky-панелі знизу — для опублікованої книги зі змінами; після натискання — «⏳ Зміни на модерації»; якщо змін немає — «✓ Усі зміни опубліковано», без кнопки.

### Обкладинка — стани (`/dashboard/books/:id/output-data/cover`, Phase 4)

- [ ] **Опублікована книга**: синій банер, картка «Обкладинку завантажено» + чип «Зміна доступна», жовта картка про 90 днів і ISBN, превʼю е-книги й друкованого розвороту поруч, перемикач М'яка/Тверда. _(Відкривається без помилок — перевірено на проді, лише перегляд.)_
- [ ] **Клік по превʼю** відкриває повноекранний перегляд; Esc або × закриває.
- [ ] **«Замінити файлом»** на опублікованій книзі: після завантаження сторінка переходить у стан «На перевірці», обидві кнопки неактивні, у магазині лишається стара обкладинка. На дашборді з'являється «Надіслати на модерацію» з блоком «Обкладинка».
- [ ] **Після схвалення адміном** — стан «🔒 Збережена обкладинка», кнопки неактивні, показано дату наступної зміни (+90 днів).

### Автообкладинка (та сама сторінка, книга БЕЗ обкладинки або неопублікована)

> Потрібна чернетка без обкладинки — в акаунті зараз усі книги опубліковані, тому цей блок на проді ще ніхто не відкривав.

- [ ] Сторінка одразу показує готову обкладинку з назвою й автором книги; під нею «Група · варіант» і «N з 14».
- [ ] Перший шаблон відповідає жанру, є чип «Підібрано за жанром «…»».
- [ ] Стрілки ‹ ›, чипи груп (Класик / Мінімал / Текстури / Патерн / Фото), стрічка мініатюр і «Інший варіант» перемикають шаблон.
- [ ] Зміна кольору теми (кружечки або «Свій») перефарбовує всі шаблони; текст лишається читабельним на будь-якому кольорі.
- [ ] «Друк» показує розворот: задня сторона (про книгу, про автора) · корінець · лицева; М'яка/Тверда змінює товщину корінця.
- [ ] Дуже довга назва: текст зменшується, але не обрізається; з'являється жовта підказка «спробуйте Мінімал».
- [ ] «Підходить, використати» зберігає обкладинку — сторінка перемикається на звичайний вигляд, обкладинка видна на дашборді й у «Передперегляді».
- [ ] Після перезавантаження сторінки пам'ятається останній обраний шаблон і колір.

### Редактор обкладинки (`/dashboard/books/:id/cover`, фаза 08)

> Зберігати на опублікованій книзі = відправити обкладинку на затвердження і почати відлік 90 днів. Для проби краще чернетка.

- [ ] Три колонки: «Шари» ліворуч, полотно по центру, «Вибране» / «Дизайн» праворуч; внизу панель з «Зберегти». _(Перевірено на проді, лише перегляд.)_
- [ ] Одразу після відкриття редактора напису «Є незбережені зміни» немає; він з'являється після першої правки.
- [ ] Фото автора й «інші книги» на задній стороні не налазять на довгу анотацію (на проді фото лягло поверх тексту — блок треба пересунути вручну).
- [ ] Клік по назві на полотні вибирає саме текст (а не фігуру під/над ним); вибраний шар підсвічено у списку «Шари».
- [ ] Клік по рядку в «Шарах» вибирає елемент на полотні й відкриває «Вибране».
- [ ] Зміна тексту назви просто на обкладинці: з'являється питання «Відв'язати від Вихідних даних?»; після «Відв'язати й змінити» значок 🔗 біля шару зникає.
- [ ] «+ Фігура» додає прямокутник; якщо він закриває текст — жовте попередження і рядок шару підсвічено.
- [ ] «Дизайн»: вибір шаблону міняє обкладинку; «⋯ → Скинути до шаблону» повертає початковий вигляд.
- [ ] Друкований формат, «Задня сторона: що показувати»: анотація, біографія, QR-код, фото автора, інші книги — кожна галочка додає/прибирає блок.
- [ ] QR-код з телефона відкриває сторінку цієї книги в магазині.
- [ ] Синій пунктир (безпечна зона) і помаранчеві лінії корінця видно на полотні, але їх немає у збереженій обкладинці.
- [ ] Undo / Redo (і Ctrl+Z / Ctrl+Y) працюють.
- [ ] «Зберегти» на чернетці: обкладинка з'являється на дашборді й на сторінці «Обкладинка».

### Вильоти для друкарні (адмінка → Книги → «Файли книги»)

- [ ] У списку файлів є рядок «Обкладинка для друкарні (розворот, вильоти 1.5 мм)»; для книги без задньої сторони чи корінця — «Немає». _(Рядок є — перевірено на проді; сам файл не завантажувався.)_
- [ ] «Скачати» віддає PNG: зліва задня сторона, посередині корінець, справа лицева.
- [ ] Розмір файлу в Photoshop / переглядачі: ширина = 2 × ширина книги + корінець + 3 мм, висота = висота книги + 3 мм, 300 dpi. Для А5 (148×210) висота має бути 213 мм.
- [ ] По краях немає білої смужки — фон продовжується до самого краю файлу.
- [ ] **Справжні вильоти в редакторі** (М'яка/Тверда): навколо обкладинки видно смужку 1,5 мм за рожевим пунктиром (лінія обрізу); фон, фото й плашки шаблону доходять до самого краю полотна, а не до пунктиру.
- [ ] Раніше збережена обкладинка відкривається без зсуву: тексти й блоки на тих самих місцях відносно краю книги.
- [ ] Е-книга: вильоту й рожевої лінії немає.
- [ ] Після «Зберегти» в редакторі: лицева/задня/корінець на дашборді — без смужки вильоту (обрізані рівно по книзі); файл для друкарні з адмінки завантажується БЕЗ попередження про дзеркальні вильоти, і на його краях — продовження самого дизайну.
- [ ] Для книги з автообкладинкою або завантаженим файлом адмінка показує попередження «вильоти дзеркальні».
- [ ] Надіслати файл у друкарню на перевірку: чи приймають PNG, чи потрібен PDF з мітками різу.
