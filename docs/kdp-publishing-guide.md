# Публікація на Amazon KDP — повний довідник для автора

> Дослідження 2026-08-17 (офіційні джерела kdp.amazon.com). Мета: дати автору повну картину перед вибором каналу "Amazon KDP" на кроці "Розповсюдження", і звірити наші власні припущення в коді.

## ⚠️ Найважливіша знахідка — реальна прогалина в нашому коді

**Українська мова на KDP підтримується ТІЛЬКИ для друкованих видань (paperback/hardcover) — Kindle-електронну книгу українською видати НЕ можна.** Пряма цитата з офіційної сторінки підтримуваних мов KDP: *"Ukrainian (paperback and hardcover only)"*. Польська та їдиш мають те саме обмеження; статус російської не перевірявся повторно в цьому дослідженні.

**Наслідок**: український автор, що вмикає канал "Amazon KDP" для своєї книги (наш `DistributionChannel`, `distributionPlatforms.ts`), сьогодні не попереджається, що електронна версія НЕ піде на Kindle — лише друкована. Це не тільки документаційна прогалина, а **реальний ризик тихої відмови на етапі доставки е-книги**, про яку автор дізнається постфактум, не заздалегідь. Потребує явної перевірки мови книги перед показом каналу KDP як доступного для е-книги, і чіткого попередження в UI.

## 1. Роялті

- **70% — ціновий діапазон $2.99–$12.99** (Amazon.com; з 7 липня 2026 розширено з $2.99–$9.99, потрібен ручний перехід для книг у діапазоні $10–$12.99). Мінус вартість доставки файлу (~$0.15/МБ за перші 10МБ на Amazon.com, залежить від маркетплейсу).
- **35% — поза цим діапазоном**, або поза KDP Select у деяких країнах, або нижче $2.99/вище $9.99 без KDP Select. **Бразилія, Японія, Мексика, Індія вимагають KDP Select для будь-якого доступу до 70%.**
- **Наш поточний показ "35–70%"** (`distributionPlatforms.ts`, показується в "Вихідні дані" крок "Огляд") — напрямок правильний, але не враховує цінову умовність. Варто додати підказку/тултіп, не просто діапазон.
- **Друк**: роялті = ціна − собівартість друку − частка Amazon (не єдиний опублікований відсоток, фактично ≈60% від ціни мінус собівартість для стандартних варіантів).

## 2. KDP Select

- Безкоштовна, **90 днів, автопродовжується**, не можна вийти достроково.
- **Повна ексклюзивність**: не можна продавати е-книгу НІДЕ ІНШЕ під час участі, **включно з власним сайтом автора**.
- Kindle Unlimited: оплата за прочитану сторінку через **KENPC** (нормалізований підрахунок сторінок), ≈$0.004–0.005/сторінка (~$1.20–1.50 за повне прочитання 300-сторінкової книги).
- Розблоковує: 5 безкоштовних промо-днів на 90-денний цикл, або один Kindle Countdown Deal.
- **Наші `Book.kdpSelectEnrolled`/`kdpSelectExpiry` (90 днів) — підтверджено коректними**, змін не потрібно.

## 3. Формати файлів та обкладинка

- **Текст е-книги**: EPUB (рекомендовано), KPF (через Kindle Create), DOCX/PDF приймаються, але якість конвертації DOCX непослідовна для складних макетів. MOBI фактично застарів на користь EPUB.
- **Обкладинка е-книги**: **тільки JPEG або TIFF** — PNG і PDF відхиляються. Рекомендовано 1600×2560px, мін. 300 DPI, RGB (не CMYK — Kindle не підтримує). Жорсткий мінімум 1000×625px. Співвідношення сторін ≈1.6:1.

## 4. KDP Print (друк за вимогою)

- **М'яка обкладинка**: 16 стандартних розмірів, від 5"×8" до 8.5"×11" (+ кастомний у межах 4–8.5" ширина / 6–11.69" висота). 24–828 сторінок.
- **Тверда обкладинка**: 5 розмірів — 5.5×8.5", 6×9", 6.14×9.21", 7×10", 8.25×11". 75–550 сторінок. Кольоровий друк — лише преміум-тир.
- **⚠️ Жоден стандартний розмір KDP не збігається з нашою таблицею ДСТУ-форматів** (130×200мм "Стандартний", 145×215мм "Енциклопедичний", 170×240мм "Збільшений", `packages/shared-types`). Метричні розміри приймаються як кастомні, але автор, що публікує і в нашому магазині, і на KDP, муситиме окремо підібрати/перевірити сумісний з KDP розмір, або ввести наш метричний розмір вручну в дюймах. Реальне тертя між платформами — врахувати в T-2059/T-2060.
- **Виліт (bleed)**: обкладинка — завжди; текстовий блок — опційно, але для всього файлу разом (не по сторінках), 3.2мм з усіх боків.
- **Поля**: зовнішнє 0.25" (без вильоту)/0.375" (з вильотом); внутрішнє (корінцеве) масштабується 0.375"→0.875" залежно від кількості сторінок (24–828).

## 5. ISBN

- **Е-книга: ISBN не потрібен** — Amazon сам присвоює безкоштовний ASIN.
- **Друк: ISBN обов'язковий.** KDP дає безкоштовний, але він **ексклюзивний для KDP** — не можна повторно використати при друку тієї самої книги через інший канал (IngramSpark, локальна друкарня, чи наш власний друкований пайплайн). Видавцем за замовчуванням буде "Independently published"/Amazon.
- **Прямий зв'язок із `docs/isbn-udc-requirements.md`**: якщо автор використовує наш платформний ISBN для друку, він НЕ повинен окремо запитувати безкоштовний ISBN у KDP для того самого видання — інакше на одну книгу буде два конфліктні ISBN.

## 6. Вимоги до вмісту/метаданих

- **Логічний Зміст (NCX) обов'язковий для всіх Kindle е-книг.** Генерується автоматично **лише якщо заголовки розділів мають стилі Word "Заголовок 1/2"** — вручну виділений жирним/великим шрифтом текст дає зламане чи відсутнє навігаційне меню. **Це прямо підтверджує правильність нашого підходу** (`extractOutlineFromDoc`, T-2057) — розпізнавання заголовків за стилями, а не текстовою евристикою.
- **Розміщення Змісту: ближче до початку, не в кінці** — офіційна вимога форматування KDP. **⚠️ Це прямо конфліктує** зі знахідкою з глосарію конструкції книги (`docs/book-construction-glossary.md`) про слов'янську конвенцію "Зміст зазвичай в кінці книги". Реальне міжринкове протиріччя — **важливий аргумент для відкритого питання позиції TOC у T-2057**: якщо дбаємо про сумісність із KDP-експортом, "на початку" — не просто стилістичний вибір, а вимога Amazon.
- **Категорії**: 3 на кожен формат (е-книга/м'яка/тверда обираються окремо), обираються з власного переліку категорій браузингу Amazon (не сирі BISAC-коди напряму).
- **Ключові слова**: 7 слотів, по 50 символів.

## 7. Податки та виплати

- **Обов'язкове податкове інтерв'ю США для ВСІХ авторів**, включно з не-США. Форма **W-8BEN** (чи W-8BEN-E для юросіб) для не-US осіб. Ім'я/адреса мають точно збігатись із зареєстрованими даними, інакше перевірка банку не проходить.
- **Дефолтне утримання 30% з дохіду з джерел у США**, якщо податкове інтерв'ю не встановлює пільгову ставку за угодою про уникнення подвійного оподаткування — точна ставка для України **не перевірена** в цьому дослідженні, потребує окремої перевірки.
- **Графік виплат**: ≈60 днів після завершення місяця продажів (90 днів для Expanded Distribution). Напр., продажі за січень — виплата в кінці березня.
- **Пороги виплат**: прямий депозит — без мінімуму; чек ≈$100 мінімум; переказ/EFT ≈$10–25 (залежить від валюти/країни).

## Невизначене/неперевірене — не приймати як факт без додаткової перевірки
- Точна ставка податкової угоди Україна–США (ймовірно лишається 30% дефолт без угоди, не підтверджено)
- Точний статус російської мови на KDP (не потрапила в "лише друк"-групу за побіжним переглядом, повторно не перевірено)
- Чи досі приймається DOCX-завантаження е-книги 2026 року для мов, обмежених лише друком (для української це, ймовірно, неактуально — вона й так лише друк — але стосується будь-якої іншої мови з подібним обмеженням)
