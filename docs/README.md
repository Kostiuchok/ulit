## Правила

- Новий документ — у відповідну папку, не в корінь `docs/`. У корені лише робочі файли зверху.
- Переміщуючи файл, шукати посилання на старий шлях: на документи посилаються коментарі в коді (`apps/`, `packages/`), а `docs/design/dashboard-ui/cover-styles/tokens.json` читає тест `apps/api/src/__tests__/cover-theme.test.ts`.
- Тексти в `legal/` — робочі копії. Сайт їх не читає: після правок текст треба перенести в код (де саме — сказано в кожному файлі).
